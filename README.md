# FinSight — محلل القوائم المالية المصورية (EAS) بالذكاء الاصطناعي

رفع PDF ممسوح أو Excel → استخراج موثق بسجل قرارات (بوابة صدق من 4 حالات) →
60 مؤشرًا + نماذج إفلاس أكاديمية + تقييم صحة مالية → تقارير Excel/HTML.

## النشر على Streamlit Community Cloud
1. New app ← اختر هذا المستودع ← main ← app.py
2. Settings → Secrets → الصق الأسرار (GEMINI_API_KEYS وGEMINI_MODEL وREPORT_LANGUAGE)
3. Deploy

التفاصيل في .env.example.
